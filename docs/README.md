# docs/ — 文档索引

本目录是提交材料的**文档部分**。所有内容与仓库中的实现一一对应，可交叉核对。

| 目录 | 内容 |
| --- | --- |
| [`report/`](report/) | **技术报告**（`.pdf` 提交版 + `.docx` 可编辑版） |
| [`ai/`](ai/) | **自定义 Skill**（大赛硬性要求）与 AI 知识沉淀 |
| [`build/`](build/) | 构建、烧录、上板、分区、状态机口径等工程文档 |

## report/ — 技术报告

按大赛官方《作品提交模板》撰写，含摘要、3.1 绪论、3.2 系统方案设计、3.3 核心算法与技术原理、
3.4 系统实现、3.5 系统测试与结果分析、3.6 AI-Native 开发说明、3.7 总结与展望，
以及评审维度对照表。

- `技术报告-低功耗离线全国矢量地图导航自行车码表.pdf` —— 提交版（含架构图/流程图/启动链图）
- `技术报告-低功耗离线全国矢量地图导航自行车码表.docx` —— 可编辑版（内容与 PDF 一致）

## ai/ — 自定义 Skill 与 AI 沉淀

- `vela-helm-one.md` —— **运行时 Skill 本体**（单文件）。拷到 `/data/agent/skills/` 即生效。
  符合 openvela `packages/ai_agent` 的加载约定：扁平 `.md`、首行标题 + 一段描述进系统提示做索引、
  正文按需 `read_file`、文件名/大小/mtime 参与哈希可热重载。
- `vela-helm-one/` —— **同源的 PC 侧深读知识库**，内容比运行时版更细、带唯一源出处与完整配方。
- `ai_native_skill.md` —— 沉淀过程、结构取舍、安装与维护约定，以及三个真实案例。

> **路径说明**：`build/` 下的文档是从主仓库 `vendor/my_vendor/docs/` 同步过来的副本，
> 其中形如 `../xxx.md` 的相对链接指向**主仓库中的相邻文档**，在本仓内可能无法直接跳转。
> 文档内容本身是自包含的；如需完整上下文，请按第四节引入 `vendor/my_vendor` 后在主仓库中查看。
